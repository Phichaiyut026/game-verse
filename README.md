# GameVerse — เว็บไซต์ขายเกม (Next.js)

ร้านขายเกมดิจิทัลที่สร้างด้วย **Next.js 16 (App Router) + React 19 + TypeScript** ใช้ไอคอนจาก `lucide-react`
ข้อมูลทั้งหมดเก็บไว้ใน `localStorage` ของเบราว์เซอร์ (เป็นเดโม ไม่มีเซิร์ฟเวอร์ฐานข้อมูลและไม่มีการชำระเงินจริง)

## เริ่มใช้งาน
```bash
npm install
npm run dev        # เปิด http://localhost:3000
npm run build      # build สำหรับ production
npm start          # รันเวอร์ชัน production
```

## ข้อมูลเกม (ดึงจาก Steam)
รายชื่อเกม 26 เกม (เช่น Call of Duty, Rust, Arma 3, Arma Reforger, DayZ, CS2, ELDEN RING, GTA V) พร้อม
รูปปก ปกแนวตั้ง ภาพหน้าจอ คำอธิบาย ผู้พัฒนา วันวางจำหน่าย ราคาเงินบาท ส่วนลด และคะแนนรีวิว
ดึงจาก Steam Store API แล้วเก็บไว้ที่ `src/lib/steam-catalog.json` (รูปภาพโหลดจาก CDN ของ Steam โดยตรง)

```bash
npm run fetch:steam   # อัปเดตราคา/ส่วนลด/รีวิวล่าสุด
```
เพิ่ม/ลบเกมได้ที่รายการ `CATALOG` ใน `scripts/fetch-steam.mjs` (ใส่ Steam appid) — หลังอัปเดตแคตตาล็อก
ให้เพิ่มเลข `DATA_VERSION` ใน `src/lib/seed.ts` เพื่อให้เบราว์เซอร์ที่มีข้อมูลเก่าอัปเดตรายการเกมอัตโนมัติ
(บัญชี คำสั่งซื้อ รีวิว และข่าวที่แอดมินสร้างจะยังอยู่)

> **ลิขสิทธิ์:** รูปภาพและชื่อเกมเป็นทรัพย์สินของผู้พัฒนา/ผู้จัดจำหน่ายแต่ละราย ใช้ได้สำหรับเดโม/ทดลองในเครื่อง
> หากจะเปิดขายจริง ต้องได้รับสิทธิ์เป็นตัวแทนจำหน่ายและใช้สื่อจากผู้จัดจำหน่ายตามเงื่อนไขของเขา

## โครงสร้างโปรเจกต์
```
src/
  app/
    (store)/            หน้าร้าน (ธีมแบบ Steam) — ใช้ layout ที่มี Header/Footer ของร้าน
      page.tsx, store/, game/[id]/, cart/, checkout/, order/[id]/, news/, login/, register/,
      library/, orders/, wishlist/, profile/, help/
    admin/              ระบบหลังบ้าน — layout แยก (sidebar + navbar) และธีมของตัวเอง (admin.css)
      page.tsx          แดชบอร์ด
      finance/          ระบบการเงิน
      games/ news/ orders/ users/ coupons/ messages/
  components/
    admin/              AdminShell (sidebar/navbar), AdminUI (KPI, กราฟ), Panels (หน้าจัดการต่าง ๆ)
  lib/
    store.tsx           state กลาง (React Context) + บันทึกลง localStorage
    finance.ts          คำนวณบัญชี: VAT, ค่าธรรมเนียม, ส่วนแบ่งผู้พัฒนา, กำไรสุทธิ, CSV
    demo.ts             สร้างยอดขายตัวอย่างย้อนหลัง 30 วัน
    seed.ts, types.ts, utils.ts
```

## ฟังก์ชัน
- หน้าแรก: แบนเนอร์สไลด์, ลดราคา, หมวดหมู่, มาใหม่, คะแนนสูงสุด, ดูล่าสุด
- ร้านค้า: ค้นหา, กรองตามประเภท/แพลตฟอร์ม/ราคา/ลดราคา/ฟรี, เรียงลำดับ (ตัวกรองอยู่ใน URL แชร์ลิงก์ได้)
- รายละเอียดเกม: แกลเลอรี, สเปก, รีวิวและให้ดาว (เฉพาะผู้ที่ซื้อแล้ว), เกมที่คล้ายกัน
- ตะกร้า + คูปองส่วนลด, ชำระเงิน (บัตร/พร้อมเพย์/TrueMoney แบบจำลอง), รับคีย์เกมทันที, รับเกมฟรี
- สมาชิก: สมัคร/เข้าสู่ระบบ, คลังเกม, ประวัติการสั่งซื้อ, รายการที่อยากได้, แก้ไขโปรไฟล์/รหัสผ่าน
- ข่าวสารและอัปเดต: แยก 4 หมวด (อัปเดตเกม/ข่าวสาร/กิจกรรม/โปรโมชั่น), ผูกกับเกมได้, ปักหมุด, นับยอดเข้าชม
  แสดงบนหน้าแรก หน้า /news และในหน้ารายละเอียดของเกมที่เกี่ยวข้อง
- ระบบการเงิน (`/admin/finance`): ทุกการซื้อจะถูกแยกเป็น VAT 7%, ค่าธรรมเนียมชำระเงิน (บัตร 3.65% / พร้อมเพย์ 1.65% / TrueMoney 2.5%),
  ส่วนแบ่งผู้พัฒนา 70% และกำไรสุทธิของร้าน — มีงบกำไรขาดทุน, กราฟยอดขาย, สัดส่วนช่องทางชำระเงิน, รายได้ตามเกม,
  ยอดค้างจ่ายผู้พัฒนาพร้อมบันทึกการจ่ายเงิน, สมุดบัญชี และส่งออก CSV (ปรับอัตราได้ที่ `src/lib/finance.ts`)
- หลังบ้าน: แดชบอร์ดยอดขาย, แจ้งเตือนคำสั่งซื้อ/ข้อความใหม่, ค้นหาคำสั่งซื้อ, เพิ่ม/แก้ไข/ลบเกม, เขียน/แก้ไข/ลบข่าว (ฉบับร่าง/เผยแพร่), คืนเงิน, จัดการผู้ใช้, คูปอง, ข้อความจากลูกค้า
- รองรับมือถือ

## ก่อนใช้งานจริง
- ย้ายข้อมูลไปฐานข้อมูลจริง (เช่น PostgreSQL + Prisma) ผ่าน Route Handlers / Server Actions
- ระบบล็อกอินฝั่งเซิร์ฟเวอร์ (เช่น Auth.js) และแฮชรหัสผ่านด้วย bcrypt/argon2
- เชื่อม payment gateway จริง (เช่น Omise / Stripe) และออกคีย์เกมฝั่งเซิร์ฟเวอร์
